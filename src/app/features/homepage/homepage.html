Demo Angular avec Vitest pour les tests

L'application comprend :

  • Une page d'accueil ( homepage )
  • L'authentification ( register - login - authService )
  • La gestion de produits ( list - details - update - add - productService )
  • Un guard pour l'accès aux routes product

Ce qui est testé :

Cible Type de test Ce qu'on vérifie
Composants ( visuel ) Unitaire ( TestBed, services mockés ) Ce qui doit être affiché l'est bien : état "chargement" avant la réponse, données du produit dans le DOM après, image absente si pas d'URL
Composants ( fonctionnel ) Unitaire ( spies sur Router et services ) Un clic déclenche la navigation avec la bonne route et les bons paramètres ( ex : /product/update/:id )
Formulaires ( login, register, add, update ) Unitaire ( composant + ReactiveForms ) Formulaire invalide → pas d'appel au service ; champ requis vide → contrôle invalide ; formulaire valide → soumission avec les bonnes valeurs
Services ( authService, productService ) Intégration ( HttpTestingController ) L'appel HTTP part vers la bonne URL avec la bonne méthode ( GET, POST, PUT ) et le bon body ; la réponse reçue correspond à ce qui est attendu ; gestion d'une réponse en erreur ( 404 / 401 )
Guard ( auth ) Unitaire ( authService mocké ) Utilisateur connecté → accès autorisé ; non connecté → accès bloqué et redirection vers /login
